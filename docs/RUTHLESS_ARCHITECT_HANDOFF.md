# Ruthless Architect Handoff

Architect Apprentice should produce a compact artifact with:

```text
ARCHITECT APPRENTICE HANDOFF

PROBLEM
...

USER DESIGN PROPOSAL
...

DECISION REVIEW
| Decision | KEEP / MODIFY / REJECT / UNRESOLVED | Why |

ACCEPTED INVARIANTS
- ...

PRODUCTION RISKS / OPEN QUESTIONS
- ...

CONCEPTS PRACTICED
- ...

TEACH-BACK QUESTIONS
1. ...

RUTHLESS-ARCHITECT HANDOFF
ready: yes | no
reason: ...
```

Ruthless Architect should treat this as **input evidence**, not approval.

It must still independently validate repository assumptions, conduct its normal requirements/design process, obtain explicit user approval, run mandatory Codex adversarial review, route implementation, and perform final acceptance.
